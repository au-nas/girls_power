# Таймер на JavaScript
Это мой первый самостоятельный компонент с логикой и интерфейсом на чистом JavaScript.
## Что я сделала

- Написала класс `TimerModule`, который создаёт таймер с кнопкой запуска и полем для ввода времени
- Таймер считает секунды и показывает, сколько времени осталось
- Если ввод неправильный, показывается сообщение с просьбой ввести число
- Вся логика написана на обычном JavaScript, без дополнительных библиотек
- Сделала простую и аккуратную стилизацию через CSS

---

## Как использовать

В файле `app.js` создаётся таймер и добавляется на страницу:

```js
import './styles.css';
import { TimerModule } from './modules/timer.module';

const timer = new TimerModule();
document.body.append(timer.toHTML());
timer.trigger();
